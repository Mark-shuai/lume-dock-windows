# 0.12.3：可移动设置窗口

## 使用方式

点击程序坞右侧的“设置”，或从托盘菜单打开设置。按住窗口顶部“程序坞设置”标题栏拖动，可移动到屏幕上的其他位置；拖动窗口边缘可调整窗口大小。关闭按钮可以关闭设置窗口，程序坞继续运行。

调整图标大小、底座宽度、玻璃圆角/透明度/模糊/高光/阴影、强调色和主题时，底部程序坞立即更新，更改自动保存。初次打开的设置窗口在工作区顶部，预留底部预览空间。位置和窗口大小在本次运行期间记住，重新启动程序后恢复初始位置；显示器变化后会把窗口限制在可见工作区。

即使开启“自动隐藏”，设置打开期间程序坞也会保持显示，关闭设置后恢复自动隐藏。设置窗口只在需要时创建，关闭后销毁。它不重复启动桌面自动扫描、右键收纳处理、运行状态/电量/歌词轮询。

两个窗口使用同一个本地存储分区，以 storage 事件同步。偏好只写入本窗口修改过的字段，快捷方式按增删与顺序变化合并，避免启动应用记录覆盖设置，或手动添加覆盖刚收纳的应用。收纳存档优先于同时扫描出的桌面原件，保存失败仍不确认删除桌面原件。

## 本次验证环境与范围

macOS arm64，Node.js 24.14.0，Electron 44.8.0。原生 Electron 窗口测试使用临时用户数据目录，不影响实际配置。Windows 安装程序由 electron-builder 跨平台构建。

- `npm test`：55 项单元测试，包含双窗口快捷方式合并、远端移除/排序/重命名保留、收纳入口优先、容量及保存失败保护。
- `npm run test:settings`：独立可移动/缩放窗口、标题拖动区与关闭按钮排除拖动、原生入口关闭启动台、主 Dock 保持显示、实时外观、双向增删与最近使用同步、单一轮询、关闭释放渲染窗口、再次打开、配置重载、小窗口滚动。
- `npm run test:ui`、`test:features`、`test:integration`、`test:stability`：桌面扫描、手动添加、保存回滚、收纳确认、大小调节、启动台、隐藏时停止工作与多次开关回归。
- `test:launcher`、`test:appearance`、`test:regressions`：启动台搜索/键盘、放大/减少动态效果/真实图标，以及透明边角和滚动边缘回归。

窗口可移动属性和标题栏拖动区域已自动检查；本机通过原生窗口调整位置验证了位置保留。Windows 11 上的实际鼠标拖动、多显示器/DPI、系统文件选择框和升级安装仍需实机检查，本记录不等同于 Windows 实测通过。

## Windows 11 实机验收

1. 打开设置，按住顶部标题栏拖动；移动过程中底部程序坞仍应显示。
2. 拖动“图标”和“宽度”滑块，再调整玻璃效果，观察底部程序坞同步改变。
3. 开启自动隐藏，设置打开时应保持预览；关闭设置后移开鼠标，程序坞应恢复隐藏。
4. 手动添加应用、重新扫描桌面、增删分隔线，两边立即同步；关闭并重启后仍保留。
5. 将设置拖到第二显示器，更改缩放比例或断开该屏，窗口应仍能在现有工作区找回。
6. 从设置选择文件和导入/导出配置，文件选择框应属于设置窗口；退出设置不应退出程序坞。
