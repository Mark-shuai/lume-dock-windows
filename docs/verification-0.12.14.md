# 0.12.14：图标按需加载与 Windows 实机检查入口

## 本版实现

- `scripts/list-apps.ps1` 只读取名称和AppID，`windows-apps.js`不再保存或返回应用清单的整批PNG；保留原有开始菜单扫描、失败降级与一分钟缓存。旧固定项中已保存的图标和自定义图标保留。
- `main.js` 的AppsFolder图标请求直接交给 `app-icon-reader.js`，不再通过重新读取完整应用清单找图片。启动台现有可见区域加载和共享图标缓存继续工作，固定/设置窗口中的所需图标也可单独读取。
- `scripts/resolve-app-icons.ps1` 使用与0.12.13字节相同的C#图标转换器，保留透明边角、半透明颜色和传统图标掩码。C#只编译一次，随后接收JSON行批次；最多一个当前读取进程，空闲2秒退出，读取超时15秒。每批最多64个，等待请求最多256个，输出缓冲最多8MiB；共享服务继续限制4个原生请求、256项/4MiB动态缓存。空闲退出后，下次需求会重新启动读取进程，有一定启动开销，需Windows实测。
- 程序退出时释放图标读取器并通过既有辅助进程登记表等待清理；旧进程迟到的输出/退出事件不会影响替代进程。读取失败回退默认图标。
- 增加 `Windows实机检查.cmd` / `npm run verify:windows`，包括原生回归、100轮交互和默认60分钟常驻采样。详见 [实机步骤](windows-validation-0.12.14.md)。只新增开发/测试工具，不增加日常运行的监控器、网络连接或搜索依赖。

## 本机已验证

宿主macOS arm64，Electron44.8.0；不是Windows实测。

- `npm test`：94项中93通过、1跳过、无失败。跳过的是需要PowerShell编译C#的用例，当前宿主没有可用PowerShell。移动后的C#与上一版已验证转换器逐字节相同，本次没有重新编译或调用Windows原生接口。
- 新增读取器测试覆盖：按需启动、中文和特殊字符作为JSON数据、批次/进程复用、空闲回收、旧退出事件隔离、部分输出、超时、错误/异常退出、畸形JSON、输出/请求数量限制、图片格式/大小和关闭清理。
- 目录测试覆盖1000项清单不保存旧PNG数据；IPC测试确认读取图标不触发清单扫描，共享缓存有效，退出后不能重启读取器。
- `test:performance`、`test:stability`、`test:launcher`、`test:categories`、`test:dedup`、`test:custom-icons`、`test:material`、`test:quit`均通过；测试的故障目录日志是有意注入。
- 短时稳定性：1000个模拟应用、40轮操作，GC后JS堆 1789180 → 1823792 字节，净增长 34612 字节。报告见 [stability-after-0.12.14.json](stability-after-0.12.14.json)。
- `npm run verify:windows -- --smoke` 验证报告入口；另执行100轮的模拟AppsFolder图标长测流程，首次打开1000项只请求47个图标（当时挂载90个网格节点），显示/解码47个；读取进程复用后空闲退出，100轮后无残留读取进程。此测试的图标辅助进程是Node模拟器，不代表真实Windows的PowerShell内存或延迟，见 [完整模拟报告](lazy-icons-synthetic-0.12.14.json)。模拟长测不强制GC，堆数字不能与上面的GC后指标直接对比。
- `npm run dist`构建Windows x64，52个打包源码文件字节比对通过，包含新增读取器和脚本；SHA-256、架构和安装器大小见 [构建校验](artifact-verification-0.12.14.json)。未配置代码签名证书。

## 尚待Windows执行

当前没有Windows执行主机，不能声称完成真实原生图标、60分钟常驻、安装升级或睡眠唤醒验证。实机脚本已加入原生AppsFolder图标、缺失应用降级、100轮交互、辅助进程空闲退出、进程树工作集/私有内存和CPU采样。

下一步把开发包搬到Windows，先执行 `Windows实机检查.cmd`（或先 `npm run verify:windows -- --quick`），然后按 [实机步骤](windows-validation-0.12.14.md) 做安装版原路径升级、托盘退出和睡眠唤醒。检查失败时保留reports目录，按报告定位后再继续添加锁屏暂停、多屏等功能。

实际节约多少内存、应用清单首开快多少，需要与同机同设置旧版比较；本版不根据“只加载47个图标”推算整个软件的内存降幅。
