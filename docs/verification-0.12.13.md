# 0.12.13：同类项目参考与搜索改进

本次独立实现 Flow Launcher 启发的名称匹配，并修复回归中发现的图标竞态。上游链接、提交、许可证和暂缓项见 [GitHub 参考评估](github-reference-review-0.12.13.md)。没有复制上游代码或新增运行依赖。

## 使用与实现

- 输入 `vsc` 可找到 Visual Studio Code，`wt` 可找到 Windows Terminal，`gchr` 可找到 Google Chrome；支持英文大小写、全角输入和驼峰词边界。
- 完整名称优先，其后为前缀、词前缀、包含、首字母与紧凑顺序字符。中文保持字面包含，别名保持可搜索，多词须全部匹配。同分按原有名称顺序排列；分类、已固定与最近使用筛选保持隔离。
- `renderer/app-search.js` 为无依赖纯函数模块，合并应用时建立索引；输入和滚动复用它，关闭面板释放。没有新增磁盘扫描、网络请求、轮询或后台进程。
- 图标请求可能在网格重绘之后、IntersectionObserver 通知之前完成。原实现此时只检查“缓存存在”并跳过读取，导致新节点保留默认图标。现在从缓存给新节点补图；保留256项/4MiB缓存上限、4个并发请求、自定义图标优先级与会话隔离。

## 验证结果

宿主：macOS arm64，Electron 44.8.0；使用隔离配置及模拟 Windows 应用数据。

- `LUME_TEST_POWERSHELL=... npm test`：88/88通过，无跳过。新增搜索评分顺序、缩写、驼峰、全角、中文、标点、多词与别名边界测试。
- `npm run test:launcher`：真实渲染器验证 vsc/gchr/wt/全角输入，不增加扫描；原有中文、IME、空状态、键盘、固定、失败重试通过。
- `test:categories`、`test:dedup`、`test:library`、`test:custom-icons` 通过，覆盖分类隔离、去重、取消固定、自定义图标和双窗口同步。测试中的目录或扫描失败日志为有意注入。
- `test:performance` 增加受控的可见区域通知延迟，稳定复现“先重绘、后缓存完成、再通知”的顺序：修复前失败，修复后通过。断言实际图片地址与解码成功，不依赖临时 CSS 标记。修复后连续3次通过。
- 1,000个模拟应用、80次搜索：清单重合并0次，20次主题变化的收录列表序列化0次，关闭面板挂载节点0个。最后一次耗时138.1ms，受宿主负载影响，不作为固定性能承诺。见 [原始性能结果](performance-after-0.12.13.json)。
- `test:stability`：1,000个应用、40轮打开/搜索/关闭、虚拟列表、异常导入、保存回滚与隐藏工作清理通过。回收后渲染器 JS 堆 1773780 → 1808228 字节，净增长 34448 字节；见 [完整报告](stability-after-0.12.13.json)。这不等于整个软件内存，短测也不能证明长期无泄漏。
- `npm run dist` 成功，Windows x64应用及安装包版本、50个源码文件字节比对和SHA-256见 [构建校验](artifact-verification-0.12.13.json)。NSIS安装器引导程序为32位，内含应用为64位，属于正常打包形式。
