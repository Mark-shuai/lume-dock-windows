# 0.12.10：应用与快捷方式分开

## 使用与分类规则

启动台标题旁新增“应用 / 快捷方式”，默认打开应用。分类按钮显示该类总数；下方“全部 / 已固定 / 最近使用”与搜索仅显示当前分类，状态行显示当前结果数。切换分类保留搜索词和筛选，重新打开启动台回到应用与全部筛选。若本类搜索为空而另一类有匹配，提示切换，不自动混入另一类结果。

- 应用：Windows AppsFolder 注册程序、EXE/COM、ClickOnce `.appref-ms` 启动文件、内置日历/便签协议，以及经现有解析器确认 EXE 或 AppID 的程序快捷方式。外观预览仍显示演示应用。
- 快捷方式：网址、文档、文件夹及尚未解析为程序的链接。未识别项可点击刷新重试识别；任意第三方协议不因名称看起来像应用而自动归类为程序。
- 同一程序的桌面、开始菜单和注册入口按现有身份合并。合并组有程序证据时只归入应用，即使代表图标来自 `.lnk` 也不重复出现在快捷方式中。不同版本、参数和工作目录保留原有区别，仅名称相同不合并。

两类均保留打开、星号固定/取消、自定义图标与最近使用。分类从已有目标和身份结果实时派生，不需要迁移旧配置，不改变文件、固定状态或启动目标。切换分类不发起额外扫描、后台进程或定时轮询，继续使用原有虚拟列表和有界图标缓存。

## 已完成验证

环境：macOS arm64，Electron 44.8.0，Windows x64 交叉构建。应用目录、身份和桌面扫描使用测试数据。

- 单元测试 78/78 通过，包括新增的目标分类、伪造分类/来源不会决定归类、网址 EXE 后缀不会误判、合并组代表项与遍历顺序不改变分类。
- `npm run test:categories`：真实 Electron 中验证两类隔离、程序别名只出现一次、同名文档不混入、搜索词保留、跨分类无结果提示、星号固定/取消保留入口、快捷方式图标编辑入口、准确目标启动、最近使用分类隔离、切换不重扫、键盘、重载，以及实际440px视口深/浅主题无横向溢出。
- `npm run test:launcher`、`test:dedup`、`test:library`：中英文/IME搜索、键盘、固定/取消及保存失败回滚、扫描只收录、别名搜索与去重、失效刷新保留旧结果、重载、独立设置同步及拥挤Dock滚动。
- `npm run test:custom-icons`、`test:appearance`：图标读取与容量限制、透明度、别名/双窗口同步、恢复、导入导出；真实图标资产、放大、减少动态效果和溢出检查。
- `npm run test:stability`：1000个模拟程序的虚拟列表、滚动到末尾、跨虚拟行键盘导航、隐藏后停止图标任务、异步响应不重建隐藏列表、40轮开关/搜索。强制GC后的渲染JS堆从3,936,084至3,963,904字节，增长27,820字节；原始记录在 `stability-report.json`。这是短时模拟结果，不是Windows总内存占用或长期无泄漏保证。
- `npm run dist` 使用保留升级修复补丁的构建脚本；打包源文件逐字节核对、Windows x64架构与安装包SHA-256见 `artifact-verification-0.12.10.json`。两个ZIP另附SHA-256并核对解压CRC与原始内容。

## Windows 11 验收

1. 退出旧版，安装0.12.10并保留配置，无需清注册表。
2. 打开全部应用，确认默认应用；已识别程序及它的桌面/开始菜单别名合并，网址、文档和文件夹仅在快捷方式中。
3. 搜索同一名称切换两类，确认搜索词保留、互不混排。测试已固定、最近使用，点星号取消后入口仍保留。
4. 在未识别的程序快捷方式上刷新，能解析的归入应用；解析失败的保留在快捷方式，仍可打开和固定。
5. 两类分别更换图标，退出重启后检查图标、固定与配置都保留；浅/深主题及不同Windows缩放下检查顶部控件和网格。
