# 0.12.7：退出和升级修复

## 修复范围

用户反馈从托盘“退出”后，升级仍提示不能关闭，并需要清除注册表。代码检查发现退出没有统一等待辅助进程关闭，且旧卸载器丢失时安装包装脚本会直接中止。这两处已修复；尚不能据此确认用户机器上的全部故障根因。

- `helper-processes.js` 统一跟踪扫描、图标、运行状态、全屏检测、电池及右键注册调用的辅助进程。退出时停止接单，终止本程序辅助进程，并等待 close，最多 1500ms。未关闭的 PID 尝试记录到 `%APPDATA%\lume-dock\shutdown-last.json`。
- `main.js` 退出先阻止新启动与窗口显示，撤销快捷键、托盘和监测，销毁 Dock/设置两个窗口，再等待辅助进程收尾并退出。重复退出请求不会重复清理。用户通过 Dock 打开的程序不进入辅助进程注册表，不会随之关闭。
- 新增 `--quit` 命令，通过单实例机制请求已有实例退出；没有运行实例时不创建 Dock。
- 安装/卸载前嵌入 `scripts/stop-installed-app.ps1`：先发退出请求，再有界等待；必要时按准确 `安装目录\Lume Dock.exe` 路径、PID 与创建时间强制结束该安装的进程。PowerShell/reg 后代还需匹配已知辅助命令，保留用户程序、用户 PowerShell 及其他目录的免安装版。不新增常驻任务。
- `scripts/upgrade-uninstall.ps1` 仍校验卸载器位置、名字与参数。准确的旧卸载器缺失时，允许 NSIS 继续覆盖程序文件并重写自身安装信息；不直接删除注册表、旧目录或用户配置。有旧卸载器但执行失败时仍停止升级，并保留同卷暂存和日志供恢复。

退出后 Windows 卸载注册信息仍存在是正常的；启用中的“加入 Lume Dock”右键菜单也会保留，方便下次通过菜单启动。退出不等于卸载。无需手动清理注册表。关闭右键收纳开关或正常卸载会移除右键菜单。

## 已完成验证

环境：macOS arm64 / Electron 44.8.0，Windows x64 交叉构建。

- `npm test`：68/68 通过，覆盖退出幂等、窗口/轮询清理、控制命令、辅助进程超时及既有功能。
- `npm run test:quit`：真实 Electron 进程测试，分别通过 app.quit 和界面退出 IPC 触发；两个窗口关闭、主进程正常退出、真实辅助进程消失，另外启动的用户程序保留。
- `npm run test:upgrade`：PowerShell Core 执行模拟 CIM/终止接口的 fixture。覆盖安装路径限定、辅助命令识别、PID 复用、不相关程序保留、缺失卸载器修复、同卷复制校验、用户数据保留和失败恢复。模拟接口不能替代 Windows CIM 实测。
- `npm run test:settings`、`npm run test:dedup`：独立设置实时预览、程序身份合并、固定取消及失败回滚通过。
- `npm run test:stability`：千应用、40 轮开关、异常配置和隐藏清理通过。渲染器 JavaScript 堆不代表 Windows 整体内存。

构建文件版本、源码字节校验及安装包哈希见 `artifact-verification-0.12.7.json`。本机没有验证 Windows 11 托盘、CIM 原生进程查询或实际升级安装。

## Windows 11 检查与安装

1. 取消并关闭旧的安装窗口，运行 0.12.7 安装包，选择原安装目录；保留 `%APPDATA%\lume-dock` 配置与收纳副本。
2. 打开设置，再从托盘“退出”，任务管理器检查本目录的 Lume Dock.exe 全部结束；程序坞辅助 PowerShell 应结束，通过 Dock 打开的其他应用继续运行。
3. 再安装到原目录，确认无需清除注册表，固定项、设置与收纳副本保留。另开一个无关 PowerShell 或其他目录免安装版，确认没有被误终止。
4. 在测试安装中备份并移走 `Uninstall Lume Dock.exe`，重新运行安装包到原目录，检查修复安装与新的卸载入口。不要在日常安装中为了测试删除注册信息或用户数据。
5. 测试卸载，以及 E:/D: 盘升级。若旧卸载仍失败，记录 `%LOCALAPPDATA%\Lume Dock\InstallerLogs` 日志与错误截图，不继续手工删注册表。免安装包可解压到新目录运行，但不会卸载旧版。
