# Icon provenance

These PNG files were converted from locally installed Apple macOS icon resources using sips. See sources.json for the original resource locations. They are used here at the user's request as default functional-entry icons and browser appearance previews. Third-party installed applications retain their own native icons.

Apple icon artwork remains the property of its respective rights holder and is excluded from the project code's MIT license. This project is independent of Apple. Animation, layout, shadows and material rendering are implemented by this project.
